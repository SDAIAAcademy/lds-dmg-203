# إدارة جودة البيانات

Data Quality Management

مسار التنفيذيين والقادة · أكاديمية سدايا · LDS-DMG-203 · المستوى 200

REPLACE: سطر واحد تحت العنوان: ما يستطيع المشارك فعله بعد المقرر

يدير المشاركون برنامجًا للجودة في مجال خدمة واحد لجهة افتراضية لا يتفق تقريرها الشهري مع أنظمتها المصدر. فيحولون المتطلبات إلى قواعد قابلة للقياس، وينمّطون جداول اصطناعية، وينفذون القواعد ويسجلون المشكلات. ثم يتتبعون خطأً متكررًا حتى منشئه، ويتفقون مع الملاك على إجراءات تصحيحية ووقائية، ويحكمون على صلاحية مجموعة بيانات ومجموعة وثائق لتدريب نظام ذكاء اصطناعي أو لتأسيس إجاباته على مصادر. وتُتناول عقود البيانات ومراقبتها على مستوى مسارات المعالجة في DEV-DAT-204.

**الصيغة:** دورة مكثفة: 3 أيام تدريبية ويوم للمشروع الختامي، مع عمل تحضيري موجه ومهمة متابعة متعقَّبة

**صفحة المقرر:** https://sdaiaacademy.github.io/lds-dmg-203/

| LO3 | ينفذ القواعد فحوصًا قابلة للتشغيل ويعرض النتائج بحسب أبعاد الجودة، باستخدام محرك فحص تصريحي والجداول التي جرى تنميطها | Applied | سجل تشغيل يغطي كل قاعدة في الكتالوج، وبطاقة أداء بحسب البعد وعنصر البيانات |
| LO4 | يشخّص السبب الجذري لمشكلة متكررة ويحدد إجراءات تصحيحية ووقائية، استنادًا إلى سجل المشكلات وتتبع أصل البيانات ومواصفة نموذج الإدخال | Performance | تحليل يسمي المنشأ والإجراءات والملاك ومقياسًا لتكرار المشكلة |
| LO5 | يقيس صلاحية البيانات لتدريب نظام ذكاء اصطناعي أو لتأسيس إجاباته على مصادر، على مجموعة بيانات جدولية ومجموعة وثائق | Applied | فجوات مقيسة في التمثيل والتسميات والتكرار والحداثة، مع قرار بالاستخدام أو الإصلاح أو الرفض |
| LO6 | يصمم خطة جودة تشمل الأولويات والقواعد والمراقبة ومسار عمل المشكلات في مجال ما، استنادًا إلى نتائج المختبرات | Performance | خطة يُدافع عنها أمام لجنة صورية |
