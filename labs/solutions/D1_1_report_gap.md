## التعريف شروطًا

حالة الرخصة `ACTIVE`، و`expiry_date` لا يسبق 2026-10-31، ومنشأة واحدة تُعد مرة، والمدينة من `centres.city_code` (المصدر الوحيد للمدينة في النظام).

## الاستعلام

```sql
WITH one AS (
  SELECT c.city_code, l.centre_id, max(l.capacity_licensed) AS cap
  FROM licences l JOIN centres c USING (centre_id)
  WHERE l.status = 'ACTIVE' AND l.expiry_date >= DATE '2026-10-31'
  GROUP BY 1, 2)
SELECT r.city_code, r.active_licences, count(*) AS by_definition,
       r.licensed_places, sum(o.cap) AS places_by_definition
FROM 'files/day1/report_2026_10.csv' r JOIN one o USING (city_code)
GROUP BY ALL ORDER BY 1;
```
