# المختبر 1.3 · قواعد لخدمة الترخيص: الحل المرجعي

التحقق: `uv run solutions/check.py 1.3`.

الكتالوج المرجعي عشرون قاعدة في `files/day2/rules_reference.csv` (يُعطى بداية للمختبر 2.3): يغطي العناصر العشرة والأبعاد الستة، ولكل قاعدة معيار اجتياز وحد تصعيد وتكرار وصاحب القاعدة (محلل جودة البيانات، كما تطلب مواصفة قواعد الجودة في الضوابط الوطنية) ومالك البيانات.

## الحكم على اقتراحات المساعد

في `reference/suggestions_review.csv`:

| | الحكم | السبب |
|---|---|---|
| S1 | رفض | رقم الهوية ليس عنصرًا حرجًا، ومطابقته بسجل جهة أخرى نقل لبيانات شخصية يحتاج أساسًا نظاميًا |
| S2 | رفض | لا عنصر ولا طريقة ولا عتبة |
| S3 | قبول | تلتقط التواريخ المقلوبة |
| S4 | قبول | المقاعد المرخصة لا تزيد على المطلوبة |
| S5 | تعديل | العتبة من حاجة المستهلك، والفراغ مقبول حيث لا يحتاجه استخدام |
| S6 | تعديل | التجديد يكرر المنشأة مشروعًا: رخصة سارية واحدة لكل منشأة |
| S7 | تعديل | كل الرموز تبدأ بصفر: المطلوب مطابقة البادئة للمدينة |
| S8 | تعديل | القائمة ثلاثة رموز لا رمزان |

## ما يُقبل من المشاركين

قواعد غير المرجعية إذا كانت قابلة للقياس، ولها معيار ومالك، وتخدم متطلبًا. لا يُقبل كتالوج أقل من 15 قاعدة أو فيه قاعدة بلا معيار اجتياز.
